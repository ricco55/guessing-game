# Guessing Game

Guess the randomly chosen number between 1 and 20.

## Features

- Higher/Lower hints after each guess
- Counts how many tries you needed
- Rejects text and asks again
- Rejects numbers outside 1–20
- Tracks your best score and says "New record!" when you beat it
- Play again option (accepts `y` or `Y`)

## What you need
- Python

## How to use it
1.  Run `python guess.py`
2.  Type a number between 1 and 20
3.  Follow the Higher/Lower hints until you find it
4.  Type `y` to play again, or `n` to quit
